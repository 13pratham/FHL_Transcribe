# YouTube Audio Downloader

A simple Python script to download audio from YouTube videos and channels.

## 📁 Project Structure

```
Youtube Videos AI/
├── working_downloader.py    # Main script (use this!)
├── requirements.txt          # Dependencies (pytubefix)
├── README.md                 # Complete usage instructions
├── .gitignore               # Git ignore rules
└── downloads/               # Downloaded audio files (MP3)
```

## 🚀 Quick Start

1. **Install dependency:**
   ```bash
   pip3 install -r requirements.txt
   ```

2. **Run the script:**
   ```bash
   python3 working_downloader.py
   ```

3. **Follow the prompts:**
   - Enter number of videos (default: 2)
   - Enter channel URL or video URL
   - Wait for downloads to complete

## 📝 Files Description

- **working_downloader.py** - Main downloader script using pytubefix
- **requirements.txt** - Python dependencies (just pytubefix)
- **README.md** - Detailed usage instructions and troubleshooting
- **.gitignore** - Excludes downloads and Python cache files
- **downloads/** - Folder where MP3 files are saved

## ✨ Features

✅ Download from channel URLs automatically  
✅ Download individual videos  
✅ Specify number of videos to download  
✅ Progress bar for each download  
✅ Automatic MP3 conversion  
✅ No API key required
